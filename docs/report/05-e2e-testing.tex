\subsection{Kiểm thử End-to-End với Playwright}
\label{sec:e2e}

Bộ kiểm thử E2E (\texttt{apps/web/e2e/order-flow.e2e.ts}) chạy trên trình duyệt thật và kiểm tra:

\begin{enumerate}
  \item Trang menu hiển thị danh sách đồ uống.
  \item Trang \texttt{/orders} yêu cầu đăng nhập khi chưa có token.
  \item Sau khi đăng ký và đăng nhập bằng API, trang \texttt{/orders} hiển thị trạng thái rỗng hoặc danh sách đơn.
  \item Luồng đầy đủ \textit{Menu $\rightarrow$ Giỏ hàng $\rightarrow$ Đặt đơn $\rightarrow$ Theo dõi} (bật bằng biến môi trường \texttt{E2E\_FULL}).
\end{enumerate}

Test được chạy bằng lệnh \texttt{npx playwright test} khi Backend và Frontend đang hoạt động.
